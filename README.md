# 👕 Interactive T-Shirt Product Display

This project is a simple interactive **T-shirt product display page** built using **HTML**, **CSS**, and **Vanilla JavaScript**.  
It allows users to:
- View a T-shirt on a model with different colors and sizes.
- Select size and color options.
- Increase or decrease quantity.
- Simulate adding to cart.

---

## 🎯 Features

- 👕 **T-shirt Preview**: Image of a model wearing the T-shirt updates based on selected color.
- 🎨 **Color Selection**: Switch between multiple color options.
- 📏 **Size Selection**: Choose between sizes like S, M, L, XL.
- ➕➖ **Quantity Control**: Increase or decrease product quantity before purchase.
- 🛒 **Order Button**: Simulate sending the product to cart or order.

---

## 🧰 Technologies Used

- **HTML** – Page structure
- **CSS** – Layout and visual styling
- **JavaScript** – Dynamic behavior and interaction
